# Portfolio Project

A modern portfolio website built using React and Vite.

## Features

* Fast Vite development environment
* Responsive design
* React components
* Clean UI
* Easy deployment with GitHub Pages or Vercel

## Technologies Used

* React
* Vite
* JavaScript
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio-project.git
```

Navigate into the project folder:

```bash
cd portfolio-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```
